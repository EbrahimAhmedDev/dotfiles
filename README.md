# ebrahim's dotfiles

Linux (Arch) dotfiles for a Hyprland setup, managed with [GNU stow](https://www.gnu.org/software/stow/).

## Structure

```
dotfiles/
├── stow/       # stow packages (each folder = one config, linked into $HOME)
├── packages/   # package lists (official + AUR), generated by sync.sh
├── copied/     # configs that must be copied, not linked (kdeglobals, mimeapps.list, ...)
├── system/     # system-level files (SDDM config & theme) applied with sudo
└── scripts/    # install.sh / sync.sh / stow-all.sh
```

## What's included

Hyprland, Waybar, Rofi, SwayNC, wlogout, Mako, Ghostty, Wob, Clipse,
Waypaper, GTK 3/4, Qt6ct, Fontconfig, Micro, btop, htop, mpv,
nwg-displays/look, Starship, Zsh and more.

## Usage

### On a new machine

```sh
git clone https://github.com/EbrahimAhmedDev/dotfiles.git ~/dotfiles
cd ~/dotfiles
./scripts/install.sh
```

`install.sh` will:

1. Install `stow` plus every package from `packages/official.txt` (and `packages/aur.txt` via `yay` if available).
2. Delete conflicting default configs, then stow-link every package into `$HOME`.
3. Copy the files in `copied/` into `~/.config`.
4. Apply the SDDM config/theme and enable SDDM.

### Day-to-day (after installing anything new)

```sh
./scripts/dotsync.sh    # or just: dotsync
```

It refreshes package lists, asks `y/N` for every new folder in `~/.config`
(press `y` for configs you want to keep), links stow packages that aren't
linked yet, then commits and pushes everything.

### On the current machine

```sh
./scripts/sync.sh      # refresh package lists, copied/ files and SDDM system files
./scripts/stow-all.sh  # move untracked ~/.config folders into stow/ and link them
```

Then commit and push as usual.

## Notes

- Everything under `stow/<pkg>/.config/...` maps to `~/.config/...` after stowing.
- Clipboard history (`clipse` history/logs) is intentionally not tracked.
