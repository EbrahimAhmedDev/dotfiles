To use the theme's original font, move the bundled
"ZenKakuGothicNew-Medium.ttf" out of this folder, then put the licensed file
here as:

    FOT-Rodin Pro DB.otf

The theme loads the first *.ttf or *.otf returned by Qt's FolderListModel, so
keep only one font file here to make the choice unambiguous. Restart SDDM / log
out to apply.

Bundled substitute: Zen Kaku Gothic New Medium (SIL OFL 1.1, see OFL.txt).
