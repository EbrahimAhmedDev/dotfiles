# NieR:Automata SDDM theme

- Theme: `nier-automata` from https://github.com/Darkkal44/qylock
  (GPL-3.0, see the upstream repository for the full license text).
- Font bundled in `font/`: **Zen Kaku Gothic New Medium**
  (SIL Open Font License 1.1, license text in `font/OFL.txt`).
  The theme's own font, `FOT-Rodin Pro DB.otf`, is commercially licensed and
  is not redistributed here; drop it into `font/` to restore the exact look
  (see `font/README.txt`).

Installed to `/usr/share/sddm/themes/nier-automata` and selected through
`system/sddm/sddm.conf.d/20-nier.conf`.
